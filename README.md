# financial-modeling-bata-india
This is a financial modeling project I built to understand how a company's financials translate into valuation.

I created a 3-statement model and a basic DCF for Bata India.

## What I did

- Built income statement, balance sheet, and cash flow linkage  
- Projected revenue and costs based on assumptions  
- Created a DCF to estimate intrinsic value  

## Why I did this

Coming from an operations and analytics background, I wanted to understand the financial side of businesses better — not just track numbers, but understand what drives them.
